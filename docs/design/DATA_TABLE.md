# 数据表 (Data table) — 设计与路线图

目标:在 quiet.md 里加一个「数据表」文档类型,**高度参考飞书多维表格 (Bitable)**,
在产品设计、UI 和交互细节上尽可能 100% 还原。本文件记录对飞书实物的研究、落地的
架构、以及分阶段路线图。实现以代码里的 `feishu_theme` token 为准;和本文对不上时以代码为准。

> 研究来源:在飞书 Web 端(登录态)新建一个空白多维表格,逐一测量其 DOM 的
> computed styles、抓取字段类型选择器、工具栏与网格结构。关键发现记录在下面。

## 一、对飞书的实物研究

### 1. 核心设计 token(实测)

| 用途 | 值 | 对应 `feishu_theme` |
|------|-----|---------------------|
| 主色(主蓝) | `#1456F0` | `ud::B600` / `Theme::primary()` |
| 正文色 | `#1F2329` | `ud::N900` / `Theme::text()` |
| 次要文字 | `#646A73` | `ud::N600` / `Theme::text_caption()` |
| 占位/弱文字 | `#8F959E` | `ud::N500` / `Theme::text_placeholder()` |
| 网格线 | `#DEE0E3` | `ud::N300` / `Theme::table_line()` |
| 表头底色 | `#F2F3F5` | `ud::N100` / `Theme::table_header()` |
| 悬浮填充 | `rgba(31,35,41,.08)` | `Theme::fill_hover()` |
| 阴影 | `rgba(31,35,41,.1)` | `Theme::shadow_*()` |
| 按钮 | 高 32px,圆角 6px,字号 14px | — |
| 表头行高 | 40px | `HEADER_H` |
| 正文字体 | LarkHackSafariFont → PingFang SC / system | `UI_FONT` |

> quiet.md 的 `src/feishu_theme.rs` 已内置整套飞书 UD 色板(N/B/R/O 色阶),实测值
> 与之完全吻合(`B600=0x1456f0`、`N900=0x1f2329`)。数据表直接复用这些语义 token。

### 2. 架构事实:网格是 canvas 自绘的

飞书多维表格的数据区是一张 `<canvas>`(实测 1668×748,无 DOM 单元格),表头/工具栏/
弹层才是 DOM。它用虚拟化 + 自绘来扛大数据量。**这对 GPUI 是利好**:GPUI 本身就是即时
模式自绘,我们天然走「自己画单元格」的路线,不必塞一堆 DOM 节点。

### 3. 字段类型体系(29 种,三组)

完整抓取自字段类型选择器,分三组(`FieldType::group()` 对应):

- **常规 (General, 12)**:文本、单选、多选、人员、群组、日期、附件、数字、复选框、
  超链接、公式、查找引用
- **业务 (Business, 11)**:流程、按钮、自动编号、电话号码、Email、地理位置、条码、
  签字、进度、货币、评分
- **高级 (Advanced, 6)**:双向关联、单向关联、创建人、修改人、创建时间、最后更新时间

其中「公式 / 查找引用 / 自动编号 / 创建人 / 修改人 / 创建时间 / 最后更新时间」是**派生
字段**,不存可编辑值(`FieldType::is_editable()` 为 false)。

### 4. 布局结构

- **顶栏**:面包屑(空间 › 用户 › 表名)、分享、自动化、图标组、问问 AI、头像。
- **左侧内部导航栏**:搜索 + 加号;数据表(选中,蓝)、仪表盘、工作流;底部「新建」。
  (这是「多维表格 = 一个 base 容纳多张表 + 仪表盘 + 工作流」的容器导航。)
- **视图页签条**:表格(选中,带图标)、+ 新建视图。
- **工具栏(一行)**:添加记录▾ | 字段配置 | 视图配置 | 筛选 | 分组 | 排序 | 行高 |
  填色 … 右侧:AI、智能提醒、生成页面、撤销/重做、搜索、评论。
- **网格**:行号/勾选列(~44px)+ 各字段列 + 末尾「+」加字段列;首列(标题列)冻结;
  底部「+」加记录行。
- **加字段弹窗**:标题输入、字段类型(可展开完整类型列表)、默认值、推荐类型、取消/确定。
- **单选/多选**:彩色标签(浅底 + 饱和文字),有一套约 10 色的标签色板。

## 二、已落地(stage 1)

### 引擎:`crates/core/src/datatable.rs`(不依赖 GPUI)

- `FieldType`:29 种类型 + `label()`(中文)+ `group()` + `is_editable()` + `all()`(按
  飞书顺序)。
- `Field { id, name, ty, config, width }`;`FieldConfig` 扁平、字段全 `#[serde(default)]`
  (加类型不破坏旧存档):options / precision / currency / rating_max / date_format。
- `SelectOption { id, name, color }`:color 是色板槽位索引(不让引擎依赖 GPUI 颜色)。
- `CellValue`:`Empty / Text / Number / Checkbox / Select / Date / Url / Person / Rating /
  Link`,`as_plain()` 给搜索/复制/Markdown 导出用;货币/进度格式化。
- `Record { id, cells, created, modified }`、`RowHeight`(低/中/高/超高)、
  `View { field_order, hidden, row_height, frozen, kind }`、`ViewKind`(表格/看板/画册/甘特/表单)。
- `Table`:fields / records / views;`blank()` 复刻飞书默认(1 个文本标题列 + 5 空行 +
  1 表格视图);`primary()` 标题列不可删;增删字段/记录、设置单元格、JSON 持久化。
- 8 个单元测试覆盖:默认表、字段体系计数(12/11/6=29)、增删与设值、标题列保护、
  单选渲染、删字段清单元格、JSON 往返、货币/进度格式化。

### 界面:`src/datatable_view.rs`(GPUI)

- `View::DataTable` + `Workspace.datatable`,入口在侧栏「新建」菜单的「数据表」。
- 全部用 `feishu_theme` token,与飞书对齐。
- 已还原:顶栏(返回 + 表名)、视图页签条、工具栏(添加记录/字段配置/筛选/分组/排序/
  行高/填色)、网格(行号勾选列 + 字段表头带类型图标 + 末尾加字段「+」+ 加记录行)。
- 单元格按类型渲染:文本、数字(右对齐)、货币/进度(格式化)、单选/多选(彩标)、
  复选框、评分(星)、日期、超链接、人员。
- 交互:单元格选中(蓝环)、文本/数字内联编辑(双击进入,回车/失焦提交)、加记录、
  加字段(飞书式分组类型选择器弹层)、复选框即点切换、评分即点、单选下拉选项、行高菜单。
- 示例数据(「任务管理」表)内置,方便审阅视觉还原度。

## 二之二、已落地(stage 2,交互深化)

本轮用「MacBook 实跑 + GPUI 离屏 `shot`」的截图回路逐项对飞书还原,全部 `scripts/check.sh`
零警告通过,每项都有实跑截图验证:

- **列拖拽改宽**:表头右缘抓手,拖动实时改列宽(悬浮显示飞书蓝条,限最小宽)。
- **表头/表体横向同步滚动**:两者合入一个横向滚动容器,表头固定在顶、表体纵向滚动,
  改宽/溢出不再错位。(**冻结首列**仍未做,见下。)
- **日期选择器**:点日期单元格弹出飞书式月历(‹ 月 ›、周一起始、今天描边、选中填蓝),
  选日写回。补了 Nucleo `chevron-left` 图标。
- **网格键盘导航**:方向键移动选中格、Tab/Shift-Tab 走格(行尾换行)、Enter 编辑文本格
  /切换复选框、Space 切换复选框、Esc 取消选中。打开数据表即聚焦工作区收键。
- **单选/多选选项编辑**:下拉内带搜索框,输入新名出「新建」行(取下一个色板色并应用);
  每个选项有 ⋯ 进入「编辑选项」面板(10 色色板改色、删除选项并清理所有单元格)。
- **多选单元格**:点选项是增删而非替换,菜单保持打开、已选项都打勾;demo 加了「标签」多选列。
- **行选中与删除**:行号勾选框真正选行(表头勾选框全选),选中行蓝底;底部浮「已选 N 条」
  条可删除/取消。
- **字段编辑器**:字段菜单「编辑字段」打开编辑器(改名 + 从分组类型列表换类型,当前类型打勾;
  标题列类型锁定为文本)。

## 三、路线图(未完成,按优先级)

1. **冻结首列**:横向滚动时标题列固定。飞书是 canvas 冻结;GPUI 需两段布局 + 共享滚动句柄
   (已评估:单帧同步有风险,待交互式验证后再做)。
2. **列拖拽换序**。
3. **人员选择器 / 附件单元格**:人员选成员列表、附件上传缩略。
4. **行右键菜单**:插入/复制/删除记录(现有底部批量条只覆盖删除)。
5. **工具栏功能**:筛选 / 分组 / 排序 / 填色真正生效(作用在 `View` 上;行高已生效)。
6. **多视图与 base 容器**:视图页签新建/切换(表格/看板/画册/甘特/表单);左侧内部导航
   栏(数据表/仪表盘/工作流),即「一个 base 多张表」。
7. **store 持久化接入**:把数据表做成新的文档类型存进文档库(JSON sidecar 或独立扩展名),
   接入侧栏、打开流程、回收站、版本历史。现在是内存态 demo。
   - 架构约束:引擎逻辑留在 `crates/core`;如涉及文档结构仍走既有 `store` 约定,
     新字段 `#[serde(default)]`,必要时 `store::FORMAT` 加一。
8. **公式 / 关联 / 查找引用**:派生字段求值引擎。
9. **字段类型图标精修**:ft-* 已自绘 10 个,其余类型仍用近似映射。

## 四、注意

- `src/datatable_view.rs::SELECT_PALETTE` 是标签色板(近似飞书),后续可按实测微调。
- **冻结首列**是剩下最硬的还原点:当前模型下标题列会随横滚移走。两种实现(绝对定位冻结层
  叠加 / 两段真实分栏 + 共享 `ScrollHandle`)都因「单帧同步 + 嵌套滚动」有风险,且 harness
  单帧拖拽难验证,故暂缓,留给交互式验证时做。
- 截图回路:`scratchpad/iterate.sh`(同步到 MacBook `~/projects/previews/quiet-md-datatable`
  → 编译 devtools → `open -n` 取 Aqua 会话 → harness 离屏 `shot` → scp 回本机)。
